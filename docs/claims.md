## Утверждения из описания продукта (переданы заказчиком 16.10.2026) — нужна правка

Для пищевой добавки в ЕС запрещено приписывать свойства профилактики, лечения или излечения болезней (Reg. UE 1169/2011 ст. 7(3), Reg. UE 1924/2006, D.Lgs. 169/2004). Эти формулировки на страницу **не вынесены**; ниже — предложения на согласование.

| Исходная формулировка | Проблема | Предложение |
|---|---|---|
| «Eliminates pain and inflammation», «quickly relieves joint pain caused by arthrosis… hernia» | Лечебное заявление, упоминание болезней | Не использовать. Описывать состав и разрешённые заявления |
| «Restores joint tissue: supports cartilage regeneration» | Не разрешено ни для продукта, ни для глюкозамина/хондроитина | «La vitamina C contribuisce alla normale formazione del collagene per la normale funzione delle cartilagini» (п. 17) |
| «Natural ingredients with anti-inflammatory and analgesic effects», «pinched nerve» | Лечебное заявление | Для растительных экстрактов — только формулировки из перечня Минздрава (п. 18) |
| Проблемы ЦА: артроз, артрит, грыжа, ишиас, онемение конечностей, «severe pain» | Таргетинг/тексты по заболеваниям; в Meta — нарушение правил «Personal health» | Повседневные ситуации без диагнозов (блок 2) |
| «Prima di pranzo / prima di cena» (на креативах) vs «at lunch / in the evening» (в описании) | Расхождение способа применения | На странице — «a pranzo / la sera». Сверить с этикеткой |
